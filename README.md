# Pet Simulator

A simple original browser pet-collector game built around one core loop:

**break objects → earn coins → hatch stronger pets → unlock the next world**

## Included
- Exactly 5 worlds: Meadow, Desert, Ice, Volcano, Space
- Third-person camera behind and above the player
- Roblox-style controls
- Pets follow the player and attack selected objects
- Eggs hatch stronger pets
- Best 4 pets auto-equip
- Locked gates between worlds
- Desktop + iPad/mobile controls
- Browser save

## Controls
### Desktop
- WASD / arrow keys: move
- Space: jump
- Hold right mouse + drag: rotate camera
- Mouse wheel: zoom
- Left Shift: shift lock
- Click breakables: send pets
- E: interact with nearby egg/gate

### iPad / mobile
- Left joystick: move
- Right-side swipe: rotate camera
- Pinch: zoom
- Jump button: jump
- Tap breakables: send pets
- Action button: hatch/unlock

No copyrighted Roblox or Pet Simulator assets are included.
